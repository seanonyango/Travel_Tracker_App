#  Travel Tracker App (Python + Kivy)

This project is a Travel Tracker application that I built as part of my programming coursework. The goal of the app is to help users keep track of places they want to visit and places they have already visited.

The project started as a simple console-based program and was later extended into a GUI application using Kivy. It was also my first time working with object-oriented programming and building an interactive interface.

---

##  Features

- Add new travel destinations (name, country, priority)
- Mark places as visited or unvisited
- View all tracked places
- Sort places based on visited status and priority
- Track number of places left to visit
- Interactive GUI with dynamic updates
- Data saved using JSON so progress is not lost

---

##  Tech Stack

- Python  
- Kivy (for GUI)  
- JSON (for data storage)

---

##  Project Structure

- `main.py` → Main application logic and GUI control  
- `app.kv` → GUI layout design (Kivy file)  
- `place.py` → Class representing a single place  
- `placecollection.py` → Manages all places and handles data  
- `places.json` → Stores travel data  
- `a1_classes.py` → Console-based version of the app  
- `test_place.py` / `test_placecollection.py` → Basic tests  

---

##  How to Run

1. Make sure Python is installed  
2. Install Kivy (if not already installed):
   pip install kivy
3.  Run the app:
   python main.py
